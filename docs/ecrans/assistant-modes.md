# Fiche écran — Assistant des modes (premier lancement)

**Parent :** `ActivitePrincipale`. **Suivant :** installation du mode choisi, puis accueil.

- Objectif : choisir Forge ou Gradle **sans défaut caché** (ADR-002) ; chaque page affiche apports, limites honnêtes, taille à télécharger et espace disque (constatés depuis le manifeste du canal, jamais inventés).
- Pages : bienvenue → présentation Forge → présentation Gradle → confirmation et installation (progression, annulation, reprise).
- Interactions : carte sélectionnable, CTA « Installer ce mode », retour système pagine en arrière.
- Adaptatif : plein écran téléphone, carte centrée tablette.
- REF : REF-009 (écart voulu : l'assistant choisit le mode, il ne conclut pas sur la création).
