# Fiche écran — Accueil

**Parent :** `ActivitePrincipale` (point d'entrée). **Suivants :** création de projet, import, atelier.

- Objectif : lister les projets (cartes à une ligne de méta), créer, importer ; carte « Reprendre » en tête (seul élément saturé de l'écran).
- États : vide (encadré pointillé + phrase + action, différé 300 ms), chargement (indicateur linéaire), liste.
- Interactions : nouvelle carte → atelier ; ⋯ → popup ancrée (export/renommer/supprimer, confirmation nommante).
- Adaptatif : largeur max 720 dp centrée, tablette : liste 2 colonnes.
- REF : REF-003 (principes repris).
