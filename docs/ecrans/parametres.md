# Fiche écran — Paramètres (hub à plat)

**Parent :** atelier (menu ⋯) ou accueil. **Pages :** mode de travail (installer/réparer/désinstaller l'autre mode), briques et versions, IA (fournisseurs, clés chiffrées, ce qui sort de l'appareil), stockage, À propos (licences : Forge, terminal GPL, briques).

- Règle du hub à plat : une seule page listant les destinations groupées, pas de pile de « Paramètres » imbriqués (REF-008 adapté : pages réelles, bornées).
- Interactions : changement de mode → assistant d'installation du nouveau mode ; rapport de diagnostic copiable (L8).
