Tiroir gauche — aperçu de la refonte

⚠ Aperçu d'illustration — arbres, branches, commits, compteurs et noms de fichiers sont des exemples de maquette ; dans l'application, tout sera réel (listage du disque, état Git, diagnostics). Conventions d'ergonomie : arborescence à la manière d'Android Studio, guides d'indentation à la manière de VS Code — icônes et dessins originaux (décision de licence consignée dans l'ADR, rien de copié). Jetons : colors.xml clair + sombre.

Plan de la refonte (résumé)

Lot 0 (livré) — extraction sans régression : LeftDrawerFragment + onglets (Fichiers réel, Chercher/Structure « à venir », Git = écran plein existant), WorkspaceViewModel, contrat WorkbenchHost, bus WorkspaceEvents (workbench-spi, testé), largeur unique min(320 dp, écran − 56 dp) via dimens. Lot 1 — moteur de fichiers core-files : listage paresseux borné annulable, tri naturel dossiers d'abord, filtres (cachés, .git/ jamais, générés estompés), dossiers compacts, FsOperations (créer/renommer/déplacer/copier/corbeille restaurable, atomique), modèles de fichiers, observation des dossiers étendus. Lot 2 — iconographie par type (VectorDrawables originaux, convention Android Studio) + guides d'indentation VS Code + décorations git/problèmes réelles. Lot 3 — onglet Fichiers UI : RecyclerView sur liste aplatie, vues Projet/Android, menu contextuel, sélection multiple, glisser-déposer, corbeille, synchronisation éditeur. Lot 4 — onglet Chercher : core-search (regex, mot entier, portée, globs, flux annulable), remplacement avec aperçu et annulation, « aller au fichier » flou. Lot 5 — onglet Structure : core-outline (Java, Kotlin, XML, Gradle, JSON, Markdown), tolérant au code incomplet, suivi du curseur. Lot 6 — moteur Git robuste core-git : statut exact (indexé/non indexé/conflits/suppressions), diff indexé et non indexé, branches, fetch/pull/push authentifiés (jeton au coffre, par hôte), stash, historique + graphe, cherry-pick/revert/reset, résolution de conflits, .gitignore, init. Lot 7 — onglet Git dans le tiroir (feuilles plein écran, onglets de diff dans la zone éditeur), visionneuse de diff partagée. Lot 8 — réglages « Explorateur et Git » (matrice de câblage), accessibilité, performance (20 000 fichiers), robustesse.

1 · Fichiers — arborescence, guides, décorations

Rangées de 40 dp : guides d'indentation (un trait par niveau, aligné sous le chevron du parent ; le guide du dossier du fichier actif est mis en évidence), chevrons animés, icônes par type (convention Android Studio, dessins originaux), dossiers compacts com.example.app, décorations git (point + couleur : modifié bleu, ajouté vert, non suivi teal, conflit rouge) et problèmes (pastille erreur/avertissement, héritée par les dossiers parents), fichier actif en gras sur sc_highest. Dossiers générés (build/) estompés et repliés ; .git/ jamais affiché ; .gitignore et .github/ toujours visibles.

2 · Chercher — recherche du projet

Champ avec focus à l'ouverture, bascules Aa (casse) · W (mot entier) · .* (regex), portée en menu, inclure/exclure repliable, ligne Remplacer repliable. Résultats groupés par fichier (repliables), appui → ouvre le fichier à la ligne et sélectionne l'occurrence. Flux : résultats poussés au fur et à mesure, compteur en direct, Stop, plafond annoncé. « Aller au fichier » : correspondance floue instantanée. Remplacement : aperçu par occurrence cochable, confirmation avec nombres exacts, annulation par instantané. Le bouton de recherche du dock ouvre cet onglet (finis les toasts).

3 · Structure — plan du fichier actif

Arbre repliable du fichier actif, tolérant au code incomplet (débouncé ~300 ms après la dernière frappe, hors fil UI). Java : package, imports repliés, classes/imbrications, champs, constructeurs, méthodes (signature courte), visibilité + − # ~, static/final/abstract. XML : arbre des éléments avec android:id. Suit le curseur (le symbole courant est mis en évidence) ; tri par position ou alphabétique ; recherche rapide ; appui → saute à la ligne. États vides honnêtes.

4 · Git — client complet dans le tiroir

Le Git ne quitte plus l'atelier. Sous-navigation Changements · Branches · Historique · Plus. En-tête : branche courante (chip → sélecteur), suivi distant réel (↓2 ↑1, « synchronisé il y a… »), Fetch · Pull · Push avec progression et annulation. Statut exact : indexé / non indexé / non suivi / conflits ; les suppressions sont indexées et commitées ; diff indexé (HEAD→index) ET non indexé (index→dossier). Zone de commit toujours visible, pas cachée par le clavier. Historique avec graphe ; détails en feuille plein écran ; diffs dans la zone éditeur. Tout hors fil UI, annulable, erreurs typées avec action suggérée.

5 · Variante élargie (tablette)

Sur tablette, le tiroir peut s'élargir (option) : l'arbre respire, le diff passe en côte à côte, la recherche gagne une colonne de résultat plus lisible. Mêmes composants, mêmes jetons.
